How to play

Tap a cell, then tap a digit to set it. Digits that would directly conflict with the row, column or 3×3 block of the cell are greyed out and cannot be set. Given digits are black, digits you set are blue. Tap anywhere else to deselect the cell.

Tapping a cell that contains a digit highlights its row, column and block in light red, the same digit elsewhere in red, and the empty cells that still have this digit as a pencil mark in green.

Number pad

  • Clear the selected cell (digit and pencil marks).
  • Pencil mode: digits toggle small pencil marks instead of setting the cell. Marks that become impossible are removed automatically when you set digits in the same row, column or block.
  • Undo the last digit, pencil mark, autofill or rejected hypothesis.

Buttons below the sudoku

  • Start a new sudoku and choose its level, from the easiest to the hardest. The level that is used at startup can be set in the settings.
  • Make a hypothesis (a guess), see below.
  • Reject the last hypothesis, see below.
  • Tools: fill in the pencil marks (every empty cell gets all digits that are still possible); restart this sudoku (all progress, including all hypotheses, is lost); mark mistakes (marks digits that differ from the solution in red); solve the sudoku (using the solver does not count as a solved sudoku in the history); input your own sudoku (the grid is emptied, set the digits you want, then tap the check mark that replaces the guess buttons, or choose “Finish input” in the tools, any sudoku can be entered, it is only analysed when you mark mistakes or solve it: with exactly one solution this works as for the other sudokus, a sudoku without a solution is reported, and for one with several solutions a warning is shown, then the solver fills in one of them or the mistakes are marked against one of them. Custom sudokus are not recorded in the history).

Guessing: hypotheses

For hard sudokus you sometimes have to guess. Tap the branch button and then a digit: the digit is a guess and shown in green. All digits set so far are fixed (black) and assumed to be correct, this is a save point. If the guess leads to a contradiction, tap the cross button: everything done since the last hypothesis is reverted. You can make another guess inside a guess, so you can do a depth-first search for the solution by hand. Rejecting hypotheses can be undone with the undo button.

Time and history

The time below the buttons only runs while you are solving on this page. When you finish a sudoku without the solver, its time is saved in the history (menu), together with the level and the ID of the sudoku. The current game is saved on your device, so you can close the app and continue later.

Serious Sudoku

A sudoku game for the hard puzzles, with guessing and backtracking. Free, without ads, and it works offline.

Open source

The sources are on GitHub. Based on sudoku-js by Thomas Baruchel. Icons from Ionicons.
